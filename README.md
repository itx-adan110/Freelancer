# Commonly — Global Marketplace Frontend

A professional, neutral, responsive React/Vite frontend concept for a global freelance marketplace.

## Included
- Landing page
- Service marketplace
- Project marketplace
- Categories
- Freelancer profile
- Service detail
- Project detail
- Login / signup
- Professional dashboard
- Responsive mobile navigation
- Neutral professional visual system
- Mock marketplace data
- GitHub Pages deployment workflow

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## GitHub Pages
The included workflow at `.github/workflows/deploy.yml` builds and deploys the Vite app to GitHub Pages after pushing to the repository's `main` branch.

In the repository settings, enable Pages using **GitHub Actions** if it is not already enabled.

## Important
This is a frontend-only product. Authentication, database, messaging, payments, escrow, file storage, moderation and APIs are represented by UI and mock data and must be connected to a backend before production use.
